# Migraine Tracker

Мобильное приложение для отслеживания мигрени, артериального давления, пульса и менструального цикла.

## 📱 О приложении

Migraine Tracker помогает пользователям вести детальный дневник здоровья, отслеживать приступы мигрени, контролировать давление и пульс, а также отмечать дни менструального цикла. Приложение позволяет анализировать статистику и экспортировать данные для дальнейшего анализа.

## ✨ Основные функции

### 🤕 Отслеживание мигрени
- Календарь с цветовой индикацией интенсивности боли
- Добавление нескольких записей за один день
- Указание времени начала и окончания приступа
- Выбор интенсивности боли (от 0 до 10)
- Отметка дополнительных симптомов (тошнота, светобоязнь, аура)
- Выбор триггеров (стресс, недосып, яркий свет, громкий звук, погода, голод, кофеин, алкоголь, гормоны)
- Отметка принятых лекарств (предустановленный список или своё)
- Редактирование и удаление записей
- Статистика за месяц: количество дней с мигренью, средняя и максимальная интенсивность
- Топ-3 самых частых триггеров с иконками
- Экспорт данных в CSV

### ❤️ Давление и пульс
- Объединенный экран для измерений давления и пульса
- Добавление записей с указанием времени (можно добавить только давление, только пульс или оба параметра)
- Статистика: средние, минимальные и максимальные значения
- Возрастные нормы давления с учетом пола пользователя
- Классификация давления:
  - 🟢 Оптимальное (< 120/80)
  - 🟢 Нормальное (120-129/80-84)
  - 🟡 Высокое нормальное (130-139/85-89)
  - 🟠 Гипертензия 1 степени (140-159/90-99)
  - 🔴 Гипертензия 2 степени (160-179/100-109)
  - 🔴 Гипертензия 3 степени (≥ 180/≥ 110)
  - 🟠 Пониженное (≤ 100/60)
  - 🔴 Критически низкое (≤ 90/60)
- Классификация пульса:
  - 🟢 Нормальный пульс (60-90 уд/мин)
  - 🟠 Пониженный пульс (50-59 уд/мин)
  - 🔴 Критически низкий пульс (< 50 уд/мин)
  - 🟡 Тахикардия 1 степени (91-135 уд/мин)
  - 🔴 Тахикардия 2 степени (136-185 уд/мин)
  - 🔴 Критическая тахикардия (> 185 уд/мин)
- Цветовая индикация статуса
- Удаление записей
- Экспорт данных

### 🔴 Менструальный цикл
- Календарь для отметки дней месячных
- Прогнозирование следующих периодов на основе истории
- Расчет фертильного окна и овуляции
- Уведомление за 5 дней до ожидаемого начала месячных
- Добавление событий в системный календарь
- Статистика цикла:
  - Последние месячные (с указанием дат)
  - Длина цикла (средняя, минимальная, максимальная)
  - Длительность месячных
  - Прогноз следующих месячных
  - Прогноз овуляции
- Добавление в системный календарь с выбором периода
- Экспорт данных

### 🎨 Настройки
- Смена темы оформления (светлая/темная)
- Редактирование профиля пользователя:
  - Имя
  - Дата рождения (с выбором через DatePicker)
  - Пол (Женский/Мужской)
  - Вес и рост
- Автоматический расчет ИМТ
- Экспорт всех данных в CSV файлы
- Очистка всех данных
- Информация о приложении

### 👋 Онбординг (при первом запуске)
- Приветственный экран
- Ввод личных данных (имя, дата рождения, пол, вес, рост)
- Выбор отслеживаемых разделов:
  - Мигрень
  - Давление и пульс
  - Менструальный цикл (доступен только при выборе женского пола)

## 📥 Экспорт данных

Приложение экспортирует данные в папку `Downloads/MigraineTracker/`:

1. **Профиль пользователя** (`user_profile_*.txt`) - личные данные, возраст, ИМТ
2. **Мигрень** (`migraine_calendar_*.csv`) - календарная таблица с группировкой по месяцам, отображением интенсивности боли, принятых лекарств и дней месячных
3. **Давление** (`pressure_export_*.csv`) - список всех измерений давления с указанием статуса
4. **Пульс** (`pulse_export_*.csv`) - список всех измерений пульса с указанием статуса

## 📋 Управление напоминаниями

- Создание напоминаний о приеме лекарств
- Выбор времени (8:00 - 23:00 с быстрыми кнопками)
- Настройка повторения (ежедневно, каждые 12, 8, 6, 4, 2 часа или каждый час)
- Включение/выключение напоминаний
- Удаление напоминаний

## 🛠 Технологии

- **Язык**: Kotlin
- **Минимальная версия Android**: 8.0 (API 26)
- **Архитектура**: MVVM
- **База данных**: Room
- **UI**: Material Design 3, ViewBinding
- **Асинхронность**: Coroutines, Flow
- **Уведомления**: NotificationManager, AlarmManager
- **Календарь**: CalendarContract API
